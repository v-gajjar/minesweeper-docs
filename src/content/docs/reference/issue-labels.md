---

Issue labels help keep the backlog organized and make triage predictable.

## Label usage guidelines
- Use **one primary type label** (`bug`, `enhancement`, `feature`, etc.)
- Always include **one priority label**
- Add helper labels only when applicable

### bug
Defects or unintended behavior.

### enhancement
Improvements to existing functionality.

### feature
New user-facing functionality.

### documentation
Documentation-only changes.

### refactor
Internal changes with no behavior change.

### test
Test coverage improvements.

### priority:low / medium / high
Relative urgency indicator.

### good first issue
Beginner-friendly, well-scoped tasks.
